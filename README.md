# Games CUYPY
In this game, the player is presented with four caves. Only one cave contains the correct answer.

The player must choose a cave by entering a number from 1 to 4.

## Example
Coba perhatikan goa dibawah ini

(  ) (  ) (  ) (  )

Menurut kamu dimana CUYPY berada? [1 / 2 / 3 / 4]:

The program will check the player's choice and display whether the answer is correct or incorrect.

# Tebak Kata
In this game, the player must guess a hidden word by entering one letter at a time.
The player enters a letter, and the game will reveal the correct letters in their positions.

## Example
_ _ _ _ _ _   
Silahkan tuliskan satu huruf: a  
_ _ _ _ a _   
Silahkan tuliskan satu huruf: 

The game continues until the player successfully guesses the entire word or runs out of attempts.

# Feature

- Win and lose conditions
- Interactive terminal gameplay
